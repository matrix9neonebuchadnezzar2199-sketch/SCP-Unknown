# SCP-Unknown- 収容違反ダンジョン

ブラウザで遊べる放置系ハクスラ×SCP収容物体合成実験RPG。方舟のホムンクルスのコアループを SCP 財団世界観で再構築した静的ゲーム。

## 起動

```powershell
# ブラウザで直接開く
start H:\CURSOR\SCP-Unknown\index.html

# または簡易サーバー
cd H:\CURSOR\SCP-Unknown
python -m http.server 8765
# http://localhost:8765/
```

Google ログインとクラウドセーブは `file://` では動かない。`http://localhost:8765/` か GitHub Pages から開く。Realtime Database のルールは `database.rules.json`（chat / saves / presence）を asia-southeast1 インスタンスへ公開する。

セーブデータは `localStorage`（キー: `scp-unknown-save-v1`）。アイテムアイコンは `assets/item/<id>.png`（128×128・透過PNG）。プロトコルツリーの解放アイコンは `assets/tree/<id>.png`。

## ゲームループ

1. **区画制圧** — MAP 上の自動交戦で制圧率を溜める（放置進行、操作不要）
2. **入手アイテム整理** — 戦利品を倉庫・ゴミ箱・分解へ振り分ける
3. **収容リスト** — 回収オブジェクトから新規収容体をカタログ化
4. **編成** — 主人公（常時参加）＋収容個体5体。枠ごとのステータスとクラス内訳を表示
5. **収容物体合成実験** — 収容体を親A／親Bへドラッグ＆ドロップして合成。Rev とスキルを継承。レシピがあれば交差種、結果は実行前にプレビュー。一覧はクラス／原種・交差種／Rev・Lv で絞り込み
6. **試験槽** — 7体以上所持で解放、BOSS勝利時に槽内へ XP。編成中は入れられない
7. **工廠** — 基礎部品と収容品からアイテム・装備・アーティファクトを製作。上位レシピは収容品を材料にする（分解・売却より残した方が得）
8. **装備** — 拠点メニューの「装備」から主人公の9枠を着替え。装備は個体ごとに強化（最大Lv.100、予算＋基礎部品、暫定コスト）。メインウエポンは「銃」「刃」の2ジャンル。銃はアタッチメントを装着できる（各種3モデル、個体ごとにレアとステ振れ幅）。刃はアタッチ不可だが基礎能力が高い
9. **拠点強化** — 作戦司令部Lv とプロトコルツリー。拡張は予算に加え基礎部品と収容品を消費する
10. **異能図鑑** — ポートレートカード。クラス／発見済／原種・交差種でフィルタ、番号・クラス・ランクでソート。未発見はシルエット

司令室の「MAP選択」から東京衛星図（NVG）を開き、[セキュリティ施設-JP](http://scp-jp.wikidot.com/secure-facilities-locations-jp) のサイト（生物サイト-8102、非生物の8104 など）を展開先にできる。**各地点の収容層進行は独立**。ピンは施設番号、下に種別と到達層。施設の `kind` で敵プールが変わる。`data.js` の `mapSites` に足せば今後のサイトも同じ手順で追加できる。

### 区画スキャンマップと関門

司令室（TOP）の最上段に戦術HUD風の区画図が常時稼働する。区画は最初真っ暗で、**展開チームは金色の1光点**として巡回し、周囲の円だけが明るい。円が触れた部屋は解明済みとして残る（左下に解明率）。異常個体は霧の外では見えず、光へ寄ってくる。接触すると小規模戦闘が発生し XP・予算・回収オブジェクトを得る（索敵ログに表示）。区画レイアウトは深度ごとに決定論的に生成される。**制圧率（掃討）と解明率は別メーター** — 地図を埋め尽くすだけでは関門は開かない。

**深度前進は撃破数で関門を開ける。** 撃破ごとに区画制圧率ゲージが溜まり、`4 + 深度 × 2` 体で MAX になると **BOSS挑戦** が押せる。押すと収容違反体が MAP 上に出現し、展開チームへ直進する。接触で交戦画面（HPバー＋ログ再生）が開き、終了後に入手アイテムと経験値／レベルアップのリザルトを表示する。勝てば次の区画へ自動進出する。負けると制圧率が半分戻る。

許可証は進行の関門ではなく加速装置。

| 操作 | コスト | 効果 |
|---|---|---|
| セントリーガン | 最大2基 | **解明済みの室内**に設置。射程内の敵を自動撃破。砲台クリックで削除（枠が戻る） |
| 緊急展開 | 許可証 1 | 60 秒間、巡回速度 ×2（ゲージが速く貯まる） |
| 強行突入 | 許可証 5 | 制圧率ゲージを即 MAX（キル報酬は得られない） |

関門で連敗すると原因診断が表示され、再出現までのクールダウンが伸びる（2連敗で45秒、以降45秒ずつ、上限180秒）。**編成は主人公＋収容5体（計6）を埋めること** — 戦闘は先頭の敵に攻撃が集中するため、数の不利はレベル差では覆せない（深度12以降は3体未満だとほぼ勝てない）。

司令室の構成は上から「区画探索」「展開部隊 STATUS」「拠点 / 戦術 / DB / 設定の 1 行メニュー」。区画探索は司令室 TOP のマップで行い、詳細ログは設定メニューの「ダンジョン」から開く。メニューは各項目がアイコン・項目名・Lv の 1 行表示。

## アイテム体系

### 回収等級

| 等級 | ★ | 見た目 |
|---|---|---|
| E | ★ | 無地 |
| D | ★★ | 鉄色 |
| C | ★★★ | 銅色 |
| B | ★★★★ | 銀色 |
| A | ★★★★★ | 金色 |
| S | ★★★★★★ | 虹グラデーション |
| SS | ★★★★★★★ | 虹＋キラキラ |

### 基礎部品（8種・3ティア）

T1 は金属片 / 導線 / 樹脂 / 有機組織、T2 は合金板 / 回路基板、T3 は電源セル / 異常粒子。倉庫上段の専用8枠に置き、各 9999 まで。**基礎部品は分解できない**（ゴミ箱での予算化は可）。ドロップは深度 10 で T2、深度 25 で T3 が解禁され、上位ほど出現重みが低い（T1:6 / T2:3 / T3:1）。

### 入手アイテム整理

探索の戦利品は倉庫へ直行せず未整理領域に積まれる。整理画面を開いている間も区画巡回は裏で続き、入手欄は増えた分だけ更新される。左が倉庫（上段部品・下段収容品）、中央が入手アイテム、右上がゴミ箱・右下が分解。レア度タブとソート（レア度 / 名前 / 個数 / 価値）あり。ゴミ箱・分解は金額または入手部品を出して YES/NO 確認する。

| 送り先 | 効果 |
|---|---|
| 倉庫 | 収容品は 200 スロット（1枠10個）。基礎部品は上段専用枠 |
| ゴミ箱 | 定価の 100% を予算化（確認あり） |
| 分解 | 基礎部品へ還元し専用枠へ保管（確認あり。部品自身は不可） |

倉庫スロット数・スタック上限は `state.storageSlots` / `state.partStack` / `state.itemStack` に持たせてあるので、拠点強化で拡張できる。

### クラフト

工廠（SCP-914）で基礎部品 T2/T3、収容アイテム、装備、アタッチメント、アーティファクトを製作する。**上位装備・アーティファクトは収容品を材料にする**ので、全部を分解／売却すると作れない。カテゴリ／レア度／並び替え／「制作可能のみ」で絞り込める。**製作時は YES/NO 確認**。個数はスライダーと ± で最大数まで一括製作できる。**クラフト材料は分解収率より常に多い**ため、作って分解するループは必ず損になる。

収容品の出口は三つある。売却（予算）、分解（部品）、**残して工廠／拠点拡張／装備強化に使う**。特定の収容体との交戦では対応する収容品が追加で出やすい。

### 装備（主人公）

拠点メニューの **装備** から、頭部 / 服 / アーマー / 靴 / メインウエポン / サブウエポン / アクセサリー1–3 を着ける。各装備は個体ごとに **強化 Lv.0–100**（装備ステ +0.5%/Lv、最大で +50%）。強化は予算と基礎部品（暫定コスト）で、外してもその個体に残る。

**武器ジャンル**: メインウエポンは **銃** と **刃** の2種。**銃** は個体ごとに **固有ID（uid）** を持ち、スタックせず1個体ずつ管理される。銃は **アタッチメント** 8枠（各種3モデル）を装着でき、構成は **銃の個体（uid）ごとに保存** される。装着しても倉庫の個体は減らず、同じアタッチはどの銃にも付けられる。装備選択の一覧でも各銃のアタッチ構成が見え、アイコンから変更画面へ行ける。銃を売却・分解するとその個体の設定は消える（売却は武器本体の価格のみ。アタッチの在庫は減らない）。刃はアタッチ不可の代わりに同レア帯の銃より基礎能力が高く、従来どおりスタックして保管できる。

アタッチメントは製作時に個体レア（E〜SSパラレル）とステ振れ幅がロールする。選択画面はレア／ステでフィルタできる。左側ステータスはバー付きで上限 255。**補正と装備スキルは主人公の戦闘にのみ適用**され、収容個体には乗らない。
